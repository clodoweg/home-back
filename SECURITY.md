# Politique de sécurité

Ce dépôt fait partie d'un tableau de bord domotique personnel : le front
[`home`](https://github.com/clodoweg/home) et l'API [`home-back`](https://github.com/clodoweg/home-back).
Seule la version de la branche `main`, celle qui est déployée, est maintenue.

## Signaler une vulnérabilité

Merci de **ne pas ouvrir d'issue publique** pour une faille de sécurité.

Utilisez le signalement privé de GitHub : onglet **Security** du dépôt, puis
**Report a vulnerability**. Le signalement n'est visible que du propriétaire du dépôt.

Indiquez si possible :

- le dépôt et le fichier ou la route concernés ;
- les étapes pour reproduire, ou une preuve de concept ;
- l'impact que vous envisagez.

Vous recevrez une réponse dès que possible. Le correctif est publié sur `main` puis déployé ; le
signalement est rendu public une fois corrigé, avec votre accord pour être crédité.

## Hors périmètre

- Les tests de charge ou de déni de service.
- Toute action sur l'installation réelle (Home Assistant, caméras, alarme) ou sur des comptes qui
  ne sont pas les vôtres.
- L'ingénierie sociale.
